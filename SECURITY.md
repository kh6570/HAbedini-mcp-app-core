# Security

`mcp-app-core` is a local library. It does not open a network port.

The workspace helpers reject a resolved path that is outside the root the server configured. Servers are expected to use those helpers for every file they read or write.

Report a vulnerability to the maintainer listed in `pyproject.toml` (`k.h6570@gmail.com`). Please include steps to reproduce and the version you ran. Do not open a public issue for an unfixed security bug.
